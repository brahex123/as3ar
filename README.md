# As3arBot

  As3arBot collects public product prices for As3ar (راعسأ), a Moroccan price-comparison app.

  - Respects robots.txt and stops on any disallow.
  - One request every 2 seconds or slower. No login, no CAPTCHA bypass.
  - Only public prices are kept, each with its source and date.

  To ask us to stop or change how we crawl your site, open an issue here.
